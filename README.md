## Overview

JwtAuthService is a production‑ready authentication micro‑service built with **Node.js**, **Express**, and **JSON Web Tokens (JWT)**. 
It demonstrates modern JavaScript patterns, comprehensive error handling, logging, configuration management, and testing.

## Features

- Secure password hashing with **bcrypt**
- Access token (short‑lived) and refresh token (long‑lived) flow
- Centralised configuration via environment variables
- Structured logging with **winston**
- Full TypeScript‑style JSDoc documentation
- Unit tests with **Jest**
- Ready for containerisation / CI pipelines
